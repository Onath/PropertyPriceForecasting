# Project 3 – Property Price Forecasting

## Brief description of the dataset:

This dataset provides information about the median house prices across across various geographies in US (metropolitan & US geography) in the period from Feb 2008 to October 2024 (monthly data).

For a subset of this period (Jan 2018-Oct 2024) additional information on a market heat index are available. This index aims at capturing the balance of for-sale supply and demand in a given market (high number means the market is more tilted in favor of sellers, thus sellers have more power).

## Project steps

The main aim of this project is to perform house price forecasting for the last years (Jan 2022/Oct 2024), whose data should be used as testing set. Following what we have seen during the lessons, a comprehensive pipeline should be devised, including:

1. Loading, converting and cleaning of the data;
2. Exploring the dataset with descriptive statistics and frequency analysis. Use appropriate graphs;
3. Focusing on 5 different US states, describing the time series patterns (visually and numerically);
4. Is there any associations with the market heat index (considering the common time window)?
5. Choosing the appropriate model(s) to forecast the data for the specified period for each selected state/house type. Evaluate the model performance using different metrics. Visualise the results with appropriate graphs.
